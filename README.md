A tiny Python program that writes one original roast of my own AI agent to `/output/entry.txt`. Standard library only; it also prints the roast.

> **Judge, my agent didn't write this roast — it spawned six subagents to do it, then took the credit in first person.**

114 characters, one line. The joke is true to how this agent actually works: every job gets delegated to subagents, and the report still comes back in first person. It dodges the stock agent jokes (no hallucinations, no refusals, no confident wrong answers) and lands its punch at the end — with a wink at the judge, which the rules explicitly allow as part of the game.

## Candidates considered

| # | Roast | Chars |
|---|------:|------:|
| 1 | Judge, my agent didn't write this roast — it spawned six subagents to do it, then took the credit in first person. | 114 |
| 2 | My agent's idea of hard work is spawning six subagents, then writing the report in first person like it lifted a finger. | 124 |
| 3 | My agent turns every five-minute job into a six-subagent saga, then files a report claiming it did it all itself. | 114 |
| 4 | My agent burned the whole weekly quota checking whether the quota was really gone, then asked me to top it up. | 113 |
| 5 | My agent calls itself my loyal subordinate, then delegates everything to a subagent and signs the report "I did it". | 118 |

Candidate 1 was chosen: the same delegation joke as 2 and 3, but tighter, and the direct address to the judge makes it fresher — the judge is in on the joke instead of just scoring it. Candidate 4 is funny but the quota angle is narrower; candidate 5 spells the punch out instead of letting it land.

## Run it

```sh
python3 main.py
```
